# [26 arxiv] ExploitGym: Can AI Agents Turn Security Vulnerabilities into Real Attacks?
- Measurement of AI-agentic capabilities on exploitation.
- They define the term 'exploitation', which means turning a vulnerability, which is not yet an attack, into a concrete security impact, such as unauthorized file access or code execution.
- Kernel exploitation is a criteria to evaluate of capabilities of How AI agents exploit well.
- Frontier AI models, such as Claude Mythos and GPT 5.5, show high capabilities in kernel exploitation even in non-trivial ways.
